Gateway not responding after 3 min:
  kubectl logs -l app.kubernetes.io/component=openclaw -c gateway -n {{ .Release.Namespace }}

A plugin isn't working:
  → Confirm the plugin is enabled AND its credentials are set in deployment settings.
  → Check the init log for the enabled-plugins line:
    kubectl logs -l app.kubernetes.io/component=openclaw -c init-config -n {{ .Release.Namespace }}
  → A plugin only loads when BOTH enabled=true AND its credential is non-empty.
