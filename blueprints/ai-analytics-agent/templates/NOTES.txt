STEP 1 — ADD TRACKING TO YOUR WEBSITE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Log into the Umami dashboard
2. Go to Settings → Websites → Add Website
3. Enter your domain name
4. Copy the tracking script shown
5. Paste it into the <head> of every page on your website:

   <script defer src="http://<umami-url>/script.js" data-website-id="<your-id>"></script>

Data appears within 30 seconds of the first page view.

STEP 2 — CONNECT A MESSAGING CHANNEL (optional)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You can chat with your analytics via the web Control UI immediately.
To add messaging, open OpenClaw Control UI → Channels, then:

  ─── Telegram (Easy — 2 minutes, free) ───
  1. Open Telegram, search for @BotFather
  2. Send /newbot and follow prompts to create a bot
  3. Copy the bot token (looks like: 7123456789:AAFxxx...)
  4. In Control UI → Channels → Add Telegram → paste token

  ─── Slack (Moderate — 15-30 minutes, free) ───
  1. Go to https://api.slack.com/apps → Create New App
  2. Add OAuth scopes: chat:write, channels:history, app_mentions:read
  3. Enable Events API → subscribe to message.channels and app_mention
  4. Install to workspace → copy Bot Token and Signing Secret
  5. In Control UI → Channels → Add Slack → paste both tokens

  ─── WhatsApp ───
  Note: WhatsApp requires Meta Business API approval, phone number
  verification, and has per-message costs. Not recommended for quick setup.
  See https://business.whatsapp.com/products/business-platform for details.

STEP 3 — ASK YOUR AI ANALYST

Open the Control UI or your connected Telegram/Slack bot, then ask:
  • "How many visitors did I have this week?"
  • "What are my top pages?"
  • "Where is my traffic coming from?"
  • "How many live users right now?"
  • "Compare this month to last month"

Response time:
  • Local Ollama (default): 30-120 seconds on CPU
  • With Anthropic/OpenAI key: 2-5 seconds
