# InfluxDB

E2E's Kubernetes deployment of [InfluxDB Core](https://www.influxdata.com) — the open-source time-series database built on the FDAP stack (Apache Flight, DataFusion, Arrow, Parquet). Store, query, and visualize metrics, IoT sensor data, and application telemetry at scale.

## Architecture

```
  App / Agent → Service (NodePort :8086) → InfluxDB Pod → PVC (8Gi)
```

## Requirements

- Kubernetes cluster (1 vCPU, 512MB RAM minimum)
- StorageClass supporting `ReadWriteOnce` PVCs

## Quick Start

```bash
git clone https://github.com/e2enetworks-oss/marketplace-blueprints.git
cd marketplace-blueprints

helm install influxdb blueprints/influxdb \
  --set service.type=NodePort
```

Using a values file:

```bash
cp blueprints/influxdb/values.example.yaml my-values.yaml
helm install influxdb blueprints/influxdb -f my-values.yaml
```

## Connecting

```bash
NODE_PORT=$(kubectl get svc influxdb -o jsonpath='{.spec.ports[0].nodePort}')

# InfluxDB CLI
influx config create \
  --config-name e2e \
  --host-url http://<node-ip>:<NODE_PORT> \
  --active

# Retrieve the auto-generated admin token (created by a K8s job at startup):
kubectl get secret influxdb-admin-token -o jsonpath='{.data.token}' | base64 -d
```

## Key Configuration

| Value | Default | Description |
|-------|---------|-------------|
| `auth.enabled` | `true` | Enable bearer token authentication |
| `service.type` | `ClusterIP` | Set `NodePort` for external access |
| `service.ports.http` | `8086` | InfluxDB HTTP API port |
| `persistence.size` | `8Gi` | PVC size for time-series data |
| `persistence.storageClass` | `""` | StorageClass — leave empty for cluster default |
| `createAdminTokenJob.enabled` | `true` | Auto-create an admin token on first deploy |

## Ports

| Port | Default Service Type | Notes |
|------|---------------------|-------|
| 8086 | ClusterIP | InfluxDB HTTP API — set `service.type=NodePort` or use port-forward |

Port-forward alternative:

```bash
kubectl port-forward svc/influxdb 8086:8086
# API now available at http://localhost:8086
```

## Authentication

InfluxDB Core uses bearer token authentication. The admin token is auto-generated by a Kubernetes Job at first deploy:

```bash
# Get the admin token:
kubectl get secret influxdb-admin-token -o jsonpath='{.data.token}' | base64 -d

# Use it in API calls:
curl -H "Authorization: Bearer <token>" http://<node-ip>:<node-port>/api/v2/buckets
```

## Troubleshooting

**Pod stuck in Pending** — check PVC binding: `kubectl get pvc`

**Cannot retrieve admin token** — check if the token-creation Job completed: `kubectl get jobs`

**Connection refused** — confirm `service.type=NodePort` and the node port is open

## Upgrading

```bash
helm upgrade influxdb blueprints/influxdb -f my-values.yaml
```
