Check pod status:
  kubectl get pods -n <namespace>

NIM pods (nim-cosmos, nim-nemotron) stay Pending until a GPU node is schedulable
and model weights finish downloading (~40GB total from NGC on first start).

VST note: sensor and streamprocessing pods require a GPU node when
  vst.sensor.requireGpu=true or vst.streamprocessing.requireGpu=true (default: false).
  On CPU clusters these flags are false and pods schedule normally.

Cache size warnings:
  Cosmos NIM cache:    {{ .Values.nim.cosmos.cacheSize }}  (GPU deploy needs ~80Gi)
  Nemotron NIM cache:  {{ .Values.nim.nemotron.cacheSize }}  (GPU deploy needs ~40Gi)
  Increase with: --set nim.cosmos.cacheSize=80Gi --set nim.nemotron.cacheSize=40Gi
