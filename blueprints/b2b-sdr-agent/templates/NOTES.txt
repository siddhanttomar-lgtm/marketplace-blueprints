HOW THE SDR PIPELINE WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

INTERACTIVE LANE (chat)
1. Lead messages your Telegram bot / web chat
2. {{ .Values.openclaw.sdrName }} qualifies them with BANT questions
3. The agent auto-registers the lead and optionally syncs to HubSpot

AUTONOMOUS LANE (background)
  • Scoring: each new lead is enriched + scored 0-100 on ICP fit
  • Auto-outreach: leads scoring >= {{ .Values.outreach.leadScoreThreshold }} get a personalized first email
  • Reply handling: inbound replies polled every {{ .Values.outreach.replyPollMinutes }} min, intent-classified, answered
  • Follow-ups: day {{ .Values.outreach.followUpDays }} sequence, auto-stops on reply
  • Guardrail: {{- if .Values.outreach.autoOutreachEnabled }} AUTO-SEND ON — emails send without review {{- else }} AUTO-SEND OFF — drafts go to Telegram for approval first {{- end }}
